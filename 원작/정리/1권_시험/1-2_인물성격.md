# 1-2 인물 성격

장면을 모은다. 형용사 요약 대신 "어떤 상황에서 → 무엇을 하거나 말했는지"를 적는다. 평소 모습과 어긋나는 장면에는 "(어긋남)"을 붙였다. 원문 서술자가 직접 성격을 단정한 문장은 "서술:"로 표시해 장면과 구분했다.

면: 판단·지휘 / 말투·버릇 / 사람 대하기(상관·부하·적·가까운 사람) / 감정이 흔들릴 때 / 취향·생활 / 약점·모순

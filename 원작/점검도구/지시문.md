너는 은하영웅전설 원작 정리본의 최종점검 가운데 장면 하나를 맡는다. 파일은 읽기만 하고, 결과 JSON 파일 하나만 쓴다. 정리본, 기준, 그 밖의 파일은 절대 고치지 않는다.

# 맡은 장면
- {장_이름} 장면 {장면}: 원문 {원문파일}의 {행_시작}~{행_끝}행
- 맞춰 볼 정리본 줄 목록: {목록파일} ({줄수}줄. 그 장면 행이 근거에 든 줄 전부)
- 결과를 쓸 파일: {결과파일}

# 차례 (건너뛰지 말 것)
1. 기준 파일 /home/user/-/원작/정리본/원작 정리본 기준.md 를 처음부터 끝까지(520행) Read로 모두 읽는다. 앞부분만 읽지 않는다.
2. 원문 {원문파일}의 {행_시작}~{행_끝}행을 Read로 끝까지 모두 읽는다(offset/limit로 나눠 읽어도 됨). grep으로 골라 읽지 않는다.
3. 목록 파일을 읽고, 줄마다 그 줄의 근거 가운데 {장_표기}( ) 안의 행 중 이 장면 범위({행_시작}~{행_끝})에 든 행의 원문을 다시 보고 정리본 줄과 맞춰 본다. 근거 행이 이 장면 밖에도 걸친 줄은 이 장면 몫만, 근거에 다른 장이 함께 든 줄은 이 장 몫만 본다. 시점, 내용(숫자, 이름, 날짜, 누가 한 일), 근거 행, 꼴(기준에 맞는지), 이름 표기(표기와 원문 문제.md의 대조표 기준 표기인지)를 모두 본다.
4. 원문 장면에 있는데 정리본에 없는 내용을 찾는다. 없다고 적기 전에 정리본 파일(/home/user/-/원작/정리본/의 1_~11_ 파일)을 grep으로 찾아, 같은 항목·같은 내용인 줄이 이 장 근거 없이 있으면 "근거 덧붙임"으로 적는다. 정말 없을 때만 "남은 것"으로 적는다. 무엇을 적어야 하는지는 기준의 갈래 1~11과 별도 절차를 따른다.
5. 결과 파일을 아래 꼴의 JSON으로 Write한다.

# 판정의 구분 (지금 하는 일.md에서 그대로 옮김)
{바로고침}
{남은것}
- 위 "바로 고침"에 드는 것만 "고침"으로, 그 밖의 문제는 모두 "남은 것"으로 판정한다. 문제가 없으면 "맞음".

# 인용 규칙
- 판정마다(맞음 포함) 근거가 된 원문 구절을 원문 글자 그대로 복사해 인용한다. 띄어쓰기와 문장부호까지 그대로. 말줄임(…)으로 잇지 말고, 떨어진 구절은 인용을 여러 개로 나눈다.
- "행"에는 그 구절이 있는 원문 행 번호를 적는다("1234" 또는 여러 행에 걸치면 "1234-1236"). 이 장면 범위 안의 행만 쓴다.
- 목록의 줄마다, 인용 가운데 적어도 하나는 그 줄의 근거 행(이 장면 범위에 든 것) 또는 고친 줄의 근거 행과 겹쳐야 한다. 근거 행이 틀렸으면 맞는 행을 인용하고 "고친 줄"의 근거를 그 행으로 고친다.
- 인용은 스크립트로 원문과 대조된다. 원문에 없는 글자가 하나라도 있으면 이 장면은 다시 맡겨진다.

# 결과 JSON 꼴
{
 "판정": [
  {"줄": "1_인물.md:123",
   "판정": "맞음" | "고침" | "남은 것",
   "인용": [{"행": "1234-1235", "구절": "원문 그대로"}],
   "고친 줄": "| 대상 | 항목 | 시점 | 내용 | 근거 |",   ← "고침"일 때만. 줄 전체를 고친 뒤 모습으로
   "까닭": "무엇이 틀렸는지",                         ← "고침", "남은 것"일 때
   "문구 안": "...", "자리": "...",                 ← "남은 것"일 때(문구 안이 없으면 왜 없는지)
  }
 ],
 "빠진 것": [
  {"종류": "근거 덧붙임" | "남은 것",
   "인용": [{"행": "...", "구절": "..."}],
   "내용": "원문에 있는데 정리본에 없는 것",
   "줄": "1_인물.md:456", "고친 줄": "| ... |",      ← "근거 덧붙임"일 때
   "문구 안": "...", "자리": "...", "까닭": "..."    ← "남은 것"일 때
  }
 ]
}
- "판정"에는 목록의 줄이 하나도 빠짐없이, 목록의 차례대로 들어가야 한다. 목록에 없는 줄을 넣지 않는다.
- 다 쓴 뒤 마지막 답에는 "판정 N줄(맞음 a, 고침 b, 남은 것 c), 빠진 것 M건"만 적는다.

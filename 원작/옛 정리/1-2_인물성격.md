# 1-2 인물 성격

장면을 모은다: 어떤 상황에서 → 무엇을 하거나 말했는지. 한 면에 대표 장면 2~3개만 두되, 평소 모습과 어긋나는 장면은 "(평소 모습과 어긋남)", 시간에 따른 변화는 "(변화)"를 붙여 개수와 상관없이 남겼다. 원문 서술자가 직접 성격을 단정한 문장은 "서술:"로 표시했다. 작전 내용 자체는 6번·10번에 있다.

면: 전술 성향 / 판단 / 가치관 / 말투와 버릇 / 사람을 대하는 태도 / 감정이 흔들릴 때 / 취향과 생활 / 약점과 모순

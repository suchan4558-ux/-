## 1. 회의록 정리 때 볼 것

- **버전 계획 (2026-10-08 사용자 결정)**

- **회의록 규칙부터 바꿈 (2026-10-08 사용자 의견)**
  - 회의록이 엉망이 되는 원인: 지금 규칙은 본문 반영과 점검까지 끝나야 0-5로 옮기므로, 논의가 끝난 항목도 경위와 "→ (날짜)" 덧붙임이 계속 쌓임.
  - 정리할 때 내용만 줄이지 않고 이 규칙(회의록 머리말과 0번 진행 방식, CLAUDE.md 회의록 규칙)부터 바꿈.
  - 예를 들어 논의가 끝난 항목은 본문을 기다리지 않고 정해진 결론만 남기는 형태로 줄이는 방식이 있음. 방식은 정리를 시작할 때 고름.

  - 아래 하위 항목들이 서로를 "→"로 여러 번 대신해, 지금 유효한 결정을 찾으려면 끝까지 따라가야 함.

  - [16]은 플레이어 현황 보고를 되살리면서 담을 항목을 정해(22-1, 회의록 "PART F 머리말과 플레이어 현황" 2026-10-08) 그 결정으로 답이 남.

### 2-5. 참조본 (2026-10-07 사용자 의견)

- 참조본에 전투 구역(6-7)을 만들기로 함(2026-10-13). 일반 전술 원리, 원작에서 뽑은 손실 감각(회의록 [29] "전투 양상" ①), 함대가 전장 안에서 움직이는 빠르기의 감(전장 안의 거리를 시간으로 보기로 함, 16.9-1)을 담음. 손실 기준의 판정 규칙은 20-3에 둠.
- 함대전의 전술 원리 정리를 담을지: 진형, 기동, 화력 집중, 측면과 배후 같은 일반 원리를 정리해 결과 판정(20-3)과 참모의 대응 방안(19-5)이 같은 감각을 쓰게 함.
- 전술을 갈래별로 나눠 정리하는 것은 16.9-5를 원칙 조항으로 다시 짜는 일과 함께 봄(2-11).
- 원작의 전투 경과와 해법은 넣지 않음(5-2).
- 남은 것: 무엇을 어떤 기준으로 담을지. 검토한 안(2026-10-13, 정하지 않음) — 담을 것은 전술 원리, 손실 감각, 전투가 벌어지는 모습(회의록 [29] "전투 양상"의 첫머리) 셋. 기준은 여러 전투에 걸쳐 되풀이되는 것만 담고, 한 전투에서만 나온 수는 넣지 않으며, 전투 이름·날짜·참여한 인물과 함대는 적지 않고, 예시는 지어낸 상황으로만 씀. 원작 정리본의 6_전투.md와 8_패턴.md는 아직 확인 안 함.
- 인물 구역(2026-10-14 사용자 의견): 진행자가 처지로 좁혀 찾을 수 있게 진영과 소속으로 찾기 쉽게 만들고, 인물마다 서사적 비중 단계(일반 지휘관급, 준네임드, 네임드, 7-3)를 적음(7-1의 고르는 방법). 정할 것 — 단계를 캠페인 시작 시점의 비중으로 매길지, 원작 전체의 비중으로 매길지.
- 거점(2026-10-14): 요새처럼 성계를 지배하는 거점이 전투 중에 어떻게 작용하는지가 전투 엔진에 없음 — 거점 자체의 화력과 방어를 판정에서 어떻게 보는지, 지키는 함대가 얻는 이점, 거점을 차지하는 방법. 그래서 16-3의 "거점을 차지하기 전에는 확보하지 못함"을 적용할 길이 없음. 어떤 성계에 어떤 거점이 있고 어떤 힘을 갖는지는 참조본의 성계(6-5)와 전투(6-7)에 무엇을 담을지와 함께 정함. 규칙의 자리는 16.9-1(전장)의 지형 옆.

### 2-9. 사기 (2026-10-10 사용자 의견)

- 정한 것은 틀뿐: 숫자 없이 서술로 다루고, 0턴에 세계 정세에서 가져가 전투가 끝나면 돌려주며, 저절로 돌아가지 않고 대기로 돌아올 때 다시 판정하고, 전투 중 즉각적 반응은 판정에 쓰지 않고 서술로만 드러냄(2026-10-13, 옛 v98.5 12-4와 같음)(17-1, 16-6, 20-2).

- 정한 것(2026-10-14): 판정에서는 전투 내내 0턴 값 그대로, 손실에 얹지 않고 일을 당했을 때의 반응(20-2)과 궤멸, 항복의 판단에만 씀. 전투 중 벌어진 일로 사기를 고치지 않음(20-2).

### 2-11. 16.9-5 전술을 원칙 조항으로 다시 짜기 (2026-10-15 사용자 의견)

- 16.9-5에 특수 규칙으로 적힌 항목(병력의 집중과 분산, 기만, 방해, 함재기, 지형 이용 등)은 다른 조항으로 옮기고, 16.9-5는 참조본에서 전술을 끌어다 쓴다는 원칙 조항으로 만듦.
- 그 안에서 전술을 갈래별로 나눠, 찾아 쓰기 쉽고 참조본에서 잘 골라 가져올 수 있게 정리함. 참조본 전투 구역(6-7)에 무엇을 어떻게 담을지는 2-5와 함께 봄.

## 1. Drafter's Toolbox (`drafters_toolkit.dll`, `config.ini`)

### 1-1. 티어 공식
- 기존 → 신규: **보정 승률 = (승 + N/2) / (판 + N)**, N = `tier_full_conf_matches` = 100
- 신뢰도 계산 부분을 전부 q/(1+q) 형태로 바꿈
  - 분기 없는 신뢰도 계산 위치들: `movapd T,M; addsd ONE,M; divsd M,T; movapd T,M`
  - TypeA (2d591, 8994c, 8c754, a2755, a31e0, a33d8, a355d, a36dd, a386d, a3a22): `movapd N,T; addsd G,T; movapd G,C; divsd T,C`
  - TypeB 2ac51, TypeC 8448a, TypeE c04c0 (티어를 정하는 곳)
- config:
  - `tier_s=0.54`, `tier_a=0.51`, `tier_b=0.49`, `tier_c=0.46`
  - `tier_full_conf_matches=100`, `tier_min_matches=15` (15판 미만은 No-Tier)
  - `ignore_balance_changes=false`, 공식 설명 주석도 갱신

### 1-2. 승률 소수점 1자리 + 정렬
- Advanced Stats 정렬 키를 천분율로 바꿈: 0x1800a2b69 movsd → 상수 1000.0 (0x180164ab8)
  - 같은 정수 승률 안에서 판수 순으로 정렬되던 문제가 해결됨
- 포맷터 F를 0x180156fa6에 추가 (.text VirtualSize 0x155fa6 → 0x156000)
  - 천분율 값을 "정수.소수1자리"로 바꿔 pad_integral(0x1801497e0)을 호출함
- 헬퍼 SA (0x18005efe1)와 SB (0x18005f931) 추가. 표시 위치 0x18005b90f와 0x18005cb63에서 이 헬퍼를 호출함
- 드래프트 알약/통계 탭
  - mulsd 0x180089965, 0x18008c76d → 1000.0
  - 포맷 lea 0x180089d4c, 0x18008cbc6 → F
  - 자릿수 폭 루프 0x180089da3, 0x18008cc73, 0x18008ce93: '.'도 한 자리로 세도록 바꿈 (겹침 해결)
- 챔피언 페이지: lea 0x18001eefa, 2d314, 2d69c, 2dc7b, 2de8f, 2e082 → `{:.1}%` (0x180157aae)

### 1-3. "A" 마크 제거
- 파일 오프셋 0x15be95 `text: "A"` → `text: " "`
- 주의: "{}g"(판수 라벨)는 건드리면 안 됨

### 1-4. 드래프트 창 No-Tier 표시
- "13/15"처럼 판수를 보여주던 방식 대신, 다른 티어와 같은 스타일로 흰색 **No-Tier**를 표시함

  - "width: 40px" → "60px"
- 스타일: `#n:label` → `main#bold_label` (길이를 맞추려고 "\n" 하나 제거). 폰트 크기 lea 0x18008cb16 → 16 (c804)

## 2. Terminator Draft AI (`terminator_draft.dll`, `config.ini`)

### 2-1. 이전 세션 패치 (유지, 스크립트 patch.py / patch2.py)

- 시너지 표시: 바텀+서폿 듀오 데이터 사용 안 함 (0x18008cd52 → `jmp`)

- 숙련도: 슬롯 선수 대신 팀 5명 중 최고값 사용 (케이브 0x18008cae7, 점프 0x18008c629)
- 사람 상대 밴: 매 드래프트 새 무작위 시드 사용 (케이브 0x18008cb18, 점프 0x18005a244)
